# Talon Playground

浏览器内的代码编辑与运行环境,由 Talon Sandbox 提供运行时支持。

## 在线访问

[playground.sandbox.talon.net.cn](https://playground.sandbox.talon.net.cn) (beta,邀请制)

## 本地开发

```bash
pnpm install
pnpm dev
```

需要 Node 20+。开发模式默认使用本地占位运行时,无需配置 API。

## 模板

- Static HTML/CSS/JS
- React + Vite
- Vue + Vite
- Node Express
- Python Flask
